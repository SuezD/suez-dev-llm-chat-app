# Projects

## Pocket E-Reader

Suez is building a small dedicated e-reader for herself.

The goal is to make something simple, clean and purpose-built rather than recreate a full Kindle.

The device uses:

- a 4.2 inch e-paper display
- a Seeed XIAO ESP32-S3 microcontroller
- physical navigation buttons
- rechargeable battery power

The software includes:

- a main menu
- My Books
- Add Books
- a reading screen
- saved reading progress

Books are stored as plain text files.

The project originally started as a prototype using an Arduino Uno, but the Uno's memory limitations led Suez to move to an ESP32-S3.
